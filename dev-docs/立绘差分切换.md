# 立绘差分切换

```text
changeFigure:normal.png -id=hero;
changeFigureDiff:smile.png -id=hero;
```

`changeFigure` 是换立绘，`changeFigureDiff` 是同一立绘的差分替换（如换表情）。省略 `-id` 时默认操作中间立绘，也可使用 `-left` 等位置参数。

差分只改状态表中的图片地址，立绘的其余状态全部保留：变换、层级（zIndex）与混合模式、入退场设置，以及舞台上的遮挡顺序。旧图不算退场，不播放自定义退场；这些设置留给之后真正换走立绘的 `changeFigure`。

口型、眨眼图是与表情配套的整张图，差分后旧图不再适用。因此 `changeFigureDiff` 接受 `-mouthOpen`、`-mouthClose`、`-mouthHalfOpen`、`-eyesOpen`、`-eyesClose`、`-animationFlag`，并按本句参数整体替换，未写的即为不启用。仍在进行的语音口型、眨眼若使用旧表情的图，舞台会丢弃这些换图。

```text
changeFigureDiff:smile.png -id=hero -mouthOpen=smile_open.png -mouthClose=smile.png;
```

差分优先于口型眨眼：混合从 Sprite 实际显示的图开始（可能是闭嘴图，闭嘴图常与原图相同），混合期间暂停口型眨眼换图，结束后显示新差分的原图。

```text
changeFigure:normal.png -id=hero -exit=exitSlide;
changeFigureDiff:smile.png -id=hero;   // 差分，不播放 exitSlide
changeFigure:other.png -id=hero;       // smile.png 以 exitSlide 退场
```

除上述口型眨眼参数外，只接受定位与流程参数（`-id`、位置、`-next`、`-continue`、`-when`），其余参数会被忽略并给出警告；需要同时改变换、动画或模型参数时使用 `changeFigure`。没有可替换的立绘、或内容为 `none` 时不存在差分，按 `changeFigure` 处理。

Live2D 与 Spine 使用各自内置的表情、动作系统，不适用差分：源立绘或目标是模型时，本句不执行。

差分演出命名为 `animation-<key>#diff`：登记时不会去重掉同目标已有的动画演出（先 `setAnimation` 再差分时，混合与动作同时进行）；之后同目标的非并行 `setTransform`、`setAnimation`、`changeFigure` 会接管并移除它，同时差分标记被清除，上屏走回退，淡入也随之取消（旧图渐出，新图直接执行动作）。混合期间对象被锁定；对象正被其他动画锁定时同样走回退。

舞台提交时，新指令留下的临时标记（不进入存档；同一次提交内连续差分以最初的源图为起点）与实际上屏的源图和目标 URL 匹配、基准位置未变，两张静态图片的宽高及像素密度完全一致，且两者 GPU 资源已就绪时，复用容器，以 200 ms 的互补 RGBA 混合过渡。

资源未就绪、尺寸不同、跳过动画、标记过期等情况，退回淡出淡入：旧图以默认淡出退场，新对象接替旧对象的遮挡顺序，保持已有变换，仅透明度淡入。不会等待资源来争取混合，也不会为尺寸不同的图片重新计算混合几何。

标记由 `WebGAL.figureDiffManager` 实例管理，只记录源 URL 和目标 URL：脚本执行时 `mark`，舞台替换时 `consume`，每次提交结束时 `clear`。后续修改目标的变换或动画设置、丢弃未提交演出、重建舞台状态时也会清除相应标记，不保存状态快照或演出引用。混合或淡入动画注册到现有 Pixi 动画管理，由差分演出负责结束。

状态表只保存差分后的图片地址，没有额外差分字段；读档、回溯和快速预览不依赖标记来恢复图片。
