# 立绘差分切换

```text
changeFigure:normal.png -id=hero;
changeFigureDiff:smile.png -id=hero;
```

`changeFigureDiff` 使用与 `changeFigure` 相同的路径解析、目标参数和计算状态更新。省略 `-id` 时默认操作中间立绘，也可使用 `-left` 等位置参数。普通换图原有的 URL、变换和动画设置更新规则不变。

区别仅在舞台提交：新指令留下一个不进入存档的临时标记。本轮标记与实际上屏的源图和目标 URL 匹配，基准位置未变，两张静态图片的宽高及像素密度完全一致，且两者 GPU 资源已就绪时，复用容器，以 200 ms 的互补 RGBA 混合代替入退场。脚本指定自定义过渡等额外参数时不使用这项优化。

资源未就绪、尺寸不同、没有可替换的旧立绘、跳过动画、标记过期等情况，全部执行普通换图。不会等待资源来争取混合，也不会为尺寸不同的图片重新计算混合几何。`none` 后再加载没有可匹配的旧源，走普通路径。

标记由 `WebGAL.figureDiffManager` 实例管理，只记录源 URL 和目标 URL：脚本执行时 `mark`，舞台替换时 `consume`，每次提交结束时 `clear`。后续修改目标的变换或动画设置、丢弃未提交演出、重建舞台状态时也会清除相应标记，不保存状态快照或演出引用。混合动画直接注册到现有 Pixi 动画管理，由普通换图演出负责结束。

状态表只保存正常换图的结果，没有额外差分字段；读档、回溯和快速预览不依赖标记来恢复图片。
