# Pixi 6 资源管理

`AssetManager` 维护舞台对象持有关系、未来剧情窗口和资源依赖。实际下载及缓存由同版本的
`@pixi/assets` 提供；`@pixi/basis` 是该包必需的运行时依赖，不升级 Pixi。

- 舞台以 UUID 持有资源，退场完成、对象销毁后才释放。异步模型初始化另有临时持有者。
- 同一资源的加载、GPU prepare、卸载互斥。前台请求直接加载，后台只保留最新窗口，按剧情距离加载。
- 模型依赖作为资源图中的子项保留，共享图集页和 Live2D 纹理不会随单个模型实例销毁。
- 图片命中缓存时仍同步挂载。几何计算和动画启动留在原有舞台代码中。
- GIF 预热首帧但不播放；视频预热后首次使用可以直接复用，重叠播放创建独立实例。
- GPU GC 只保护仍被持有的纹理；上下文恢复后重新 prepare。
- Live2D 只预取数据及纹理，模型实例由 SDK 独立创建。SDK 使用预取 JSON 的副本。

Spine 仍默认关闭。不要将 `pixi-spine` 添加为默认依赖；用户按
<https://docs.openwebgal.com/spine.html> 自行安装并启用 `spine.ts` 中的动态导入。
启用后，适配器通过该运行时的图集和骨架解析器处理资源，不再共用繁忙的 `PIXI.Loader`。

需要运行时回归的场景：缓存命中、慢网换图、快进、退场纹理共享、口型眨眼、读档跳转、
视频重叠播放、Live2D 初始化中退场、Spine 多页图集失败重试、WebGL 上下文恢复。
